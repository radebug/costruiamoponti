# CostruiamoPonti

Portale educativo gratuito e responsive su migrazioni, insegnamento della lingua italiana, rotte migratorie e conflitti nel mondo.

## Contenuti
- Homepage e missione
- Migrazioni: contesto, definizioni, diritti
- Italiano: 5 livelli (Pre-A1, A1, A2, B1, B2), 20 unità introduttive, quiz interattivi
- Mappa didattica con 6 corridoi migratori schematici
- Mappa didattica di 9 aree selezionate di conflitto/crisi
- Biblioteca di fonti (UNHCR, OIM, ACLED, ReliefWeb, Consiglio d'Europa)

## Utilizzo
Sito statico senza backend. Apri `index.html` o pubblica i file nella root di GitHub Pages. Richiede Internet per Leaflet, OpenStreetMap e Google Fonts.

## Pubblicazione GitHub Pages
Repository → Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
Indirizzo atteso: https://radebug.github.io/costruiamoponti/

## Importante
Le rotte rappresentano collegamenti schematici e non istruzioni di viaggio. La mappa conflitti non è un monitoraggio in tempo reale. Le lezioni sono introduttive e non rilasciano certificazioni. I contenuti vanno approfonditi e verificati editorialmente prima di trattarli come fonte definitiva.
